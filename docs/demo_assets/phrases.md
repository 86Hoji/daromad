# Фразы для демо (если микрофон подвёл)

В `/app` нажмите кнопку с клавиатурой рядом с 🎤 («Matn bilan yozish»), вставьте фразу и нажмите Enter.
В Telegram просто отправьте её боту сообщением.

1. Расход, нехватка в четверг растёт (шаг 1):

   ```
   Bugun ijaraga 200 ming to'ladim
   ```

2. Долг вернули (шаг 4):

   ```
   Alisher 450 ming qarzini qaytardi
   ```

3. Вопрос, текстовый и голосовой ответ (шаг 6):

   ```
   Kim menga qarz?
   ```

`kim_menga_qarz.wav` — фраза 3 голосом. Используется как фейковый микрофон при записи `docs/demo.webm`
(см. `scripts/record_demo.mjs`), её же можно включить с телефона у микрофона ноутбука.
